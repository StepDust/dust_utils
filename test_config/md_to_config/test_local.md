①页面入口

②页面布局

⑤操作案例  
用户输入账号、密码、插入UKey并填验证码→系统校验全部要素→自动生成登录会话并输出进入值守台。

# 登录界面

![登录界面](https://rhlt-file-bed.oss-cn-hangzhou.aliyuncs.com/case_image/35092/00.登录界面.png)

按住电源键3秒，设备开机。屏幕先显示启动画面，随后进入“安全登录”界面，左侧显示平台标识、软件名称、版本号V1.0及统计信息卡片，右侧显示账号输入框、密码输入框和“进入系统”确认条。输入框未选中时显示灰色提示文字，界面背景为浅色，可操作区域以边框和底色区分。

短按顶部功能键1次，焦点在账号框、密码框和“进入系统”之间顺序切换。被选中的输入框边框加深，提示文字变浅或消失；被选中的操作条底色加深，表示当前可执行。

账号框高亮时，短按确认键进入输入状态。屏幕光标在账号框内闪烁，原有提示文字消失。通过侧边加减键逐位调整字符，通过确认键逐个输入；长按侧边键1秒，删除当前字符。再次短按确认键，退出账号输入状态。

密码框高亮时，短按确认键进入输入状态。屏幕显示密码掩码，输入内容以圆点或星号形式显示。通过侧边加减键逐位输入，通过确认键确认当前字符；长按侧边键1秒，删除上一位。再次短按确认键，结束密码输入。

将“进入系统”操作条高亮后，短按确认键执行登录。屏幕先保持当前界面1-2秒，随后进入系统主界面。若账号或密码错误，屏幕在输入框下方显示错误提示，输入框边框短暂变红后恢复默认状态。

长按返回键2秒，清除当前输入内容并将焦点返回到账号框。账号框和密码框恢复为空白状态，提示文字重新显示。

## 联网状态与统计显示

设备未联网时，屏幕底部显示演示环境提示，统计卡片显示固定演示值。设备联网后，底部显示联网状态标识，统计卡片按同步结果刷新。联网异常时，底部提示连接异常，统计卡片保持上一次有效数值。

| 状态 | 屏幕表现 | 统计数值表现 |
|---|---|---|
| 未联网 | 底部显示演示环境提示 | 显示固定演示值 |
| 联网 | 底部显示联网状态标识 | 按同步结果刷新 |
| 联网异常 | 底部提示连接异常 | 保持上一次有效数值 |

## 按键功能对照

| 物理操作 | 屏幕反馈 |
|---|---|
| 按住电源键3秒 | 设备开机，进入登录界面 |
| 短按顶部功能键1次 | 焦点在账号框、密码框、进入系统之间切换 |
| 短按确认键 | 进入输入状态或执行登录 |
| 长按侧边键1秒 | 删除当前字符 |
| 长按返回键2秒 | 清空输入并返回账号框 |

## 状态说明

| 状态 | 说明 |
|---|---|
| 开机 | 设备完成启动并显示登录界面 |
| 待输入 | 账号框或密码框处于可编辑状态 |
| 待确认 | “进入系统”操作条高亮，可执行登录 |
| 登录失败 | 输入框提示错误，等待重新输入 |
| 联网同步 | 统计数值刷新，状态提示更新 |
| 演示模式 | 使用默认测试信息，统计值为固定展示值 |
