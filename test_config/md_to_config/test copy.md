# 登录窗口
![](https://rhlt-file-bed.oss-cn-hangzhou.aliyuncs.com/case_image/32404/images_20260703095358/10.登录窗口.png)

①页面入口  
系统启动后自动进入登录窗口。

②页面布局  
包含账号密码输入区、UKey插入区、动态验证码区、状态信息展示区、操作按钮区。

③字段说明  
工号/账号：用户身份标识。  

口令：登录密码。  

硬件密钥UKey：USB安全令牌。  

动态验证码：一次性登录码。  

状态信息：TLS通道、上次登录、待复查事件。

④能力说明  
系统将校验账号、密码、UKey和验证码，自动建立TLS安全通道，记录登录日志，权限校验通过后生成会话Token。

⑤操作案例  
用户输入账号、密码、插入UKey并填验证码→系统校验全部要素→自动生成登录会话并输出进入值守台。

- P95时延：95分位响应时延  
- 重传率：消息重传占比  
- 选择器/优先级：路由条件与优先级  
- 权重：分配流量权重  
- 熔断阈值：触发熔断的条件

④ 能力说明  
系统自动统计链路实时指标，支持链路灰度、熔断操作，变更自动记录日志并同步链路状态，支持数据导出（JSON）。

⑤ 操作案例  
用户点击“熔断”→系统校验权限，变更链路状态为熔断，记录日志并同步至路由策略→前端弹窗提示操作成功。


## 操作审计追踪
![](https://rhlt-file-bed.oss-cn-hangzhou.aliyuncs.com/case_image/32404/images_20260703095358/41.操作审计追踪.png)

1. 用户筛选操作审计记录，输入检索条件→系统校验权限，查询并展示匹配操作流水→页面状态刷新，输出列表与明细日志。

2. 用户点击“导出审计日志”→系统校验导出权限，生成并下载审计日志文件（CSV），记录导出行为→页面提示导出成功。

3. 用户点击“重新验签”→系统校验权限，自动校验日志链完整性，更新验签状态→页面显示校验结果，异常时输出告警提示。
