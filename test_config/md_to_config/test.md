## 事件详情

1. 用户点击异常事件，系统自动调取事件详情，校验权限并记录访问日志，输出事件关联链路与建议处置。  
2. 用户选择“加入观察名单”，系统校验操作合法性，更新名单状态，记录操作日志，通知相关监控人员，输出名单变更结果。  
3. 用户点击“导出取证”，系统生成事件证据JSON文件，校验导出权限，记录导出日志，输出下载链接。  
4. 用户应用推荐处置，系统自动同步策略，更新事件状态，记录处置日志，通知业务方，输出处置结果。
